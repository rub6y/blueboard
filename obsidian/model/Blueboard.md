# Blueboard

Blueboard is the whiteboard application this project builds.

Blueboard is inspired by Miro's online whiteboard.

Blueboard is implemented in [[Rust]].

Blueboard is split into [[Core_crate]], [[Render_crate]], and [[App_crate]].

Blueboard renders a [[Semi_infinite_canvas]].

Blueboard's pen tool is the [[Vector_pen]].

Blueboard saves boards using the [[File_format]].

Blueboard is customized through the [[Config_file]].

Blueboard is operated through the [[Command_line]] in addition to direct mouse/pen input.

Blueboard will eventually support the [[Magic_window]] feature.
